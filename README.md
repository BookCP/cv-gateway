# CV Gateway

A personal profile page published with GitHub Pages.

- `index.html` is the website.
- `assets/` contains the logos and visual assets used by the page.
- `documents/` contains the CV, references, and certificates linked from the page.
- `wallet-pass/` contains the Google Wallet pass artwork, design settings, and local link generator.

The Wallet service-account key is private and must stay outside this repository.

Website: https://bookcp.github.io/cv-gateway/
